# 🚀 My Projects
# GreenPulse

GreenPulse est un projet Python de data analysis et d’intelligence géographique dédié à l’évaluation du potentiel des énergies renouvelables à partir de données environnementales, géographiques et climatiques.

L’objectif est d’analyser les zones les plus favorables à l’implantation de solutions énergétiques durables, en combinant :

- données climatiques
- données géographiques
- cartes et visualisations
- analyses statistiques
- scénarios d’évaluation de potentiel

Ce projet met en avant des compétences en :
- Python
- analyse de données
- géospatial analysis
- visualisation de données
- modélisation de potentiel d’énergie renouvelable

## Objectif du projet

GreenPulse vise à fournir une première estimation du potentiel d’installations renouvelables dans une zone donnée en tenant compte de plusieurs critères, tels que :

- rayonnement solaire
- vitesse du vent
- altitude / relief
- densité d’occupation du sol
- zones de production ou d’exploitation possible
- données environnementales et géographiques

Le but est d’aider à la prise de décision pour des projets d’énergie verte, de transition énergétique et de développement durable.

## Installation

1. Clone le projet :

```bash
git clone https://github.com/enahel559-cyber/GreenPulse.git
cd GreenPulse
```

2. Créez un environnement virtuel :

```bash
python -m venv venv
source venv/bin/activate   # Linux / macOS
venv\Scripts\activate      # Windows
```

3. Installez les dépendances :

```bash
pip install -r requirements.txt
```

## Utilisation

Lancez le programme principal :

```bash
python src/main.py
```

Ou ouvrez les notebooks dans le dossier `notebooks/` pour explorer les analyses pas à pas.

### 🗺️ GIS Integration

Version 3 introduces a geographic information component using
**GeoJSON and GIS tools**.

The geographic data are converted into spatial points and displayed
on an interactive map, allowing different areas to be visualized
and compared.

### 📊 Main features

- Renewable energy potential score
- Geographic data processing
- Interactive GIS map
- Area selection
- Potential classification
- Data filtering
- Comparison of different zones
- Data table and visualization

### 🧠 Scientific approach

GreenPulse uses a simplified weighted scoring model to combine
different geographic and environmental parameters.

The current model is an **educational prototype**, not a real
engineering energy assessment. Real-world analysis would require
validated solar, climatic, topographic, building and electrical-grid
data.

### 🛠️ Technologies

`Python` `Streamlit` `Pandas` `GeoJSON` `Folium` `GIS` `SAGA GIS`

### 🎯 Project objective

The objective of GreenPulse is to demonstrate how **programming,
geographic information and scientific data analysis** can be combined
to study a real-world renewable energy problem.
